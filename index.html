Comment utiliser cette suite de tests

Objectif : Cette suite permet de tester la couverture des outils d'accessibilité automatiques (Axe, Wave, Lighthouse, Pa11y, etc.) selon les critères du RGAA 3.2016.

Pour les outils automatiques :

  • Utilisez le bouton "Raw Mode" ou accédez directement à all-tests.html
  • Cette page contient tous les 125 tests avec exemples conformes et non conformes
  • Chaque test possède un ID unique (ex: #test-1-1-1) pour un ciblage précis
  • Idéal pour scanner avec Axe, Wave, Lighthouse, Pa11y, etc.

Pour la navigation :

  • Utilisez le menu latéral pour naviguer par thème RGAA (1-13)
  • Cliquez sur un test pour voir les détails et les exemples
  • Utilisez les filtres pour afficher uniquement certains types d'éléments
